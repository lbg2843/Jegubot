# config_history

과거 `.env` 설정 스냅샷 보관소.

**목적**: 데이터 분석 시 "그 기간에 봇이 어떤 파라미터로 돌았는지"(스탑로스 %,
트레일링, 포지션 사이즈, 활성 체인, 게이트 임계값 등)를 재구성하는 데 사용.
과거 거래/로그를 해석하려면 당시 설정을 맞춰봐야 하므로 삭제하지 않는다.

**git 미추적**: 이 폴더 내용은 `.gitignore`로 제외된다 (이 README만 예외).
`.env` 백업에는 API 키·텔레그램 토큰 등 시크릿이 포함되어 있어 git 히스토리에
올리지 않는다. 디스크에만 보관한다.

**파일 명명**: `.env.bak_<날짜>` = 정상 스냅샷, `.env.broken_*` = 깨진 상태 보존,
`.env.empty_*` = 빈 상태 보존, `.env.backup` = 일반 백업.
